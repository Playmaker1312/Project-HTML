Strategi Belajar Efektif

  1. Build projects: Teori hanya 20%, praktik 80%
  2. Code every day: Konsistensi lebih penting dari durasi
  3. Read others' code: Buka source code project open source
  4. Teach others: Menulis blog atau membantu di forum
  5. Follow experts: Ikuti developer senior di Twitter/GitHub
  6. Attend events: Meetup, conference, hackathon
  7. Contribute to open source: Mulai dari dokumentasi atau fix kecil
