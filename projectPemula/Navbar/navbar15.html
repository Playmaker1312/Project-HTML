Navbar Final Test

Uji di berbagai ukuran layar menggunakan DevTools

Checklist Pengujian:

  • Hamburger muncul di layar < 768px
  • Menu toggle berfungsi di mobile
  • CTA button muncul di menu mobile
  • Active state terlihat jelas
  • Sticky position berfungsi
  • Teks tidak terpotong di 320px
  • Hover effect berfungsi di desktop
  • ARIA attributes terpasang

Gunakan Chrome DevTools (F12) > Device Toolbar untuk menguji di berbagai resolusi. Pastikan semua elemen berfungsi dan terlihat dengan baik.
